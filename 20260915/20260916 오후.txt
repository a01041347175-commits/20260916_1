git : 형상(버젼) 관리 툴
git init 작성하면 선택 폴더 안에 .git 이라는 폴더 생성(로컬저장소)
git status : 현재 상태 확인 명렁어 
git add 파일명 : 로컬저장소에 저장되기 전에 stage공간에 저장 하는 명령어
git commit -m '메모내용' : 메모하여 로컬저장소로 이동 명령어
git log

소유자 정보 입력
git config --global user.email '이메일'
git config --global user.name '이름'
git config --list
clear

git log 후 commit id 확인
git checkout id(8~10자리)
git reflog
